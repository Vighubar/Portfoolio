## About the Project

This is an Arduino project made as part of an Arduino course. The idea is to model the body of a Mazda Miata MX5 and turn it into a coaster that pops up its headlights and lights up RGB lights in the front, back and underneath when an item is placed on top of it.

## The Challenge

The assignment was open ended, the goal was simply to get familiar with coding and how Arduino components work together. There wasn't really a problem to solve, it was more about learning something new in a fun and hands on way.

## The Process

I started by sketching out some design ideas by hand, then modeled the body in Fusion 360 based on an existing blueprint of the car. Along the way I got a lot of mentoring from my teacher on the Arduino side, and feedback from classmates on the 3D model. The design isn't final yet, I'm still not fully satisfied with how it turned out.

## What I Learned

This project taught me a lot of new skills all at once, soldering, modeling in Fusion 360, how Arduino actually works on a code level, and the basics of 3D printing. If I were to do it differently, I would remodel the whole body and print the mechanism in a different way. The project is still a work in progress and I'm continuing to improve it.
